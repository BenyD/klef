## Why not Doppler or Infisical?

They are good team products that serve secrets to machines and CI, which needs a server that can read them. Klef gives that up for one property they cannot offer in their hosted form: the server cannot read your secrets. If you need team access control or secrets injected into CI, use one of them. If you are one developer with several machines, Klef is the smaller, simpler answer.

## Can Klef, or whoever runs the server, read my env files?

No. Files are encrypted on your device before upload, with a key derived from a passphrase the server never receives. The server sees ciphertext, plus the names of your workspaces, projects and files. See [End-to-end encryption](/docs/concepts/encryption/).

## What can a coding agent see?

Key names, file names and counts. No Klef command prints a value, and the agent cannot unlock a device on its own; you approve that in the browser, or at a terminal. The env file the CLI writes is plaintext on disk, though, so an agent that reads it directly would see the values. The instructions `klef setup` writes tell agents not to, and to use `klef run` when a task needs a value: it starts a program with the variables in its environment, and the agent sees only that program's output. See [Using Klef with Claude Code and Cursor](/docs/guides/coding-agents/).

## I forgot my passphrase.

Use your recovery key: on the unlock screen, choose "Forgot your passphrase? Use your recovery key", then set a new passphrase. See [Passphrase, passkeys and recovery key](/docs/concepts/unlocking/).

## I lost my passphrase and my recovery key.

Then the data cannot be recovered, by you or by Klef. That is what zero-knowledge means: there is no reset anyone could perform, because nobody else has the keys.

## What happens if klef.sh goes away?

Export any file from the app at any time, and the code is open source under AGPL-3.0, so you can [host it yourself](/docs/guides/self-hosting/) with one deploy. Your env files also live on your machines as ordinary files.

## Does it work with teams?

No. Klef is personal: one account, one vault. There is no sharing or team access control.

## What does the CLI need?

Node.js 22.18 or newer. It runs on macOS, Linux and Windows. Unlocking at login keeps the key in the OS keychain on all three; only the time-limited `klef unlock --for`, which needs the unlock agent, is not available on Windows yet.

## Which files can I store?

Any text file. Dotenv files get the table view, linting and key-level diffs; other formats are stored and versioned as text. Klef stores exactly the bytes you saved.

## Does Klef push to Vercel, GitHub or Cloudflare?

No. `klef audit` reads key names from those platforms through your own CLIs, and never writes to them. See [Auditing](/docs/guides/audit/).

## Is there a cost?

Klef at klef.sh is free for one developer. Pro ($4 a month) and Team ($12 a month for up to 5 people) are not open yet; you can reserve one on the [pricing page](https://klef.sh/pricing) without paying anything. Self-hosting is free forever, with every feature, and costs only whatever your Cloudflare usage costs.

## Does Klef track me?

No analytics, trackers, ads or third-party scripts. See the [privacy policy](https://klef.sh/privacy).
