Klef's web app deploys continuously from `main`; the CLI is versioned on npm as [`@klefsh/cli`](https://www.npmjs.com/package/@klefsh/cli). Full history is in the [repository](https://github.com/BenyD/klef/pulls?q=is%3Apr+is%3Amerged).

## Unreleased

- **Sign in once, unlocked.** Approving `klef login` in the browser can also unlock the CLI: the page asks for your passkey or passphrase and sends the vault key sealed to that terminal, end to end. The CLI keeps it in the OS keychain, so pull, push, sync, diff and restore never ask for the passphrase on that device, in your terminal or in a coding agent. `klef unlock` does the same from a terminal; `klef lock` and `klef logout` forget the key; `klef login --no-remember` keeps none. `klef status` says how the vault is unlocked.
- **A sharper `klef audit`.** GitHub secrets are compared with what `.github/workflows` references: referenced but not set, and set but never referenced. Every Worker in the repo is audited against its own secrets. An environment with nothing set is one "unused environment" line. `.klef.json` can map a scope to its file under `audit`. `klef setup` ends with the same check as counts.

## CLI 0.6.0

Published to npm as `@klefsh/cli@0.6.0`:

- `klef setup`: sign in, link, write agent instructions for Claude Code and Cursor, unlock and pull, in one rerunnable command.
- `klef sync`: push or pull each linked file, whichever side changed, and stop on conflicts.
- `klef diff`: compare local files with the vault by key name.
- `klef restore`: pull every linked checkout under a directory on a new machine.
- `klef audit`: compare key names with Vercel, GitHub Actions and Cloudflare Workers, read-only.
- `klef unlock` and `klef lock`: one passphrase for a run of commands, held by a background agent; `--for` keeps it for up to 7 days of idle time.
- `pull --all` and `push --all`: every file listed in `.klef.json`.
- `link` records `.env.local` and `.env.production` when the project has them.
- Conventional output and input for every command: `--json` everywhere, as one object with a fixed error code and runnable `next` commands; stable exit codes; per-command help with examples (`klef help <command>`); unknown commands and flags rejected with a suggestion; colour that respects `NO_COLOR`; `-q`, `-y`, `--no-input` and `-C`; shell completion; and no prompt where nobody can answer it. `klef status` reports each file's sync state without the passphrase. The JSON of `status`, `list` and `audit` moved into the envelope's `data`.

## October 2026

- Environments worked out from file names, in the app and the CLI. Labels show only when they add something.
- A redesigned app: one sidebar for navigation, a new dark theme, a command menu with search, and file tabs.
- Sign-in lasts 30 days. "Keep unlocked for 7 days" is an opt-in on the unlock screen, with longer auto-lock choices (8 hours, 1 day, 7 days).
- Agent prompts for Claude Code and Cursor in the app and on the landing page.
- A rebuilt landing page and security page.

## September 2026

- A fix for Google sign-in.
